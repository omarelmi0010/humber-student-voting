# Humber Student Voting Website – Project Plan

## 1. Project Concept and Purpose
- Who it's for: Humber students, similar to IGNITE elections, where students vote for their student union representatives.
- Problem it solves: Solves low student participation in elections (like what happened with IGNITE) by making voting more convenient and accessible online, with clear candidate/topic info.
- Uniqueness: Live voting results displayed with a chart (Chart.js), making the process transparent and engaging.

## Main Features
1. Voting form (select a candidate, click to vote)
2. Live results display (chart showing vote counts)
3. Candidate profile section (name, bio, photo)

## User Experience
- Homepage: Welcome message + "Vote Now" button
- Navigation: Simple top menu (Home, Vote, Results)
- Look and feel: Minimalist

## 2. Technologies and Tools
- Frontend: HTML, CSS, JavaScript
- Library: Chart.js (for live results display)
- Deployment: GitHub Pages

## 3. Project Roles
Solo project — all roles handled by one member:
- Frontend Developer: HTML/CSS structure and styling
- JavaScript Developer: Voting logic and Chart.js integration
- Team Lead: GitHub repo, Issues, Project Board
- Design Specialist: Minimalist, clean, accessible design

## 4. Detailed Feature Breakdown
Feature: Voting Form
- Display list of candidates on voting page
- Add "Vote" button next to each candidate
- Use JavaScript to record vote on click
- Show confirmation message after voting

Feature: Live Results Display
- Store vote counts using JavaScript
- Use Chart.js to create a bar chart
- Update chart automatically on new vote

Feature: Candidate Profile Section
- Create a card per candidate (name, photo, short bio)
- Display all candidate cards on voting page

## 5. Project Workflow and GitHub Setup
- GitHub repository created for the project
- Branch naming: feature/voting-form, feature/results-chart, bugfix/<description>
- Main branch protected — pull requests required before merging
- GitHub Issues created for each feature/task
- Project Board columns: To Do, In Progress, Done

## 6. Timeline
- Week 1: Project plan + GitHub repo/Project Board setup
- Week 2: Homepage + candidate profile layout (HTML/CSS)
- Week 3: Voting form + live results chart (JavaScript)
- Week 4: Testing, bug fixes, final review, deployment

- Introduction: Humber student voting website, inspired by IGNITE elections
- Demo: Voting form, candidate profiles, live results chart
